# Jwala Kumar - Applied Intelligence Portfolio

Welcome to the source code for my professional portfolio. 

## About
This portfolio showcases my work as a Data Analyst, Full Stack Developer, and Machine Learning Engineer. It is designed around the concept of "Applied Intelligence," transforming messy signals into structured, useful systems.

## Features
- **3D Particle Data Wave:** A fully interactive, WebGL-powered 3D particle background built with Three.js.
- **Interactive Physics:** Particles dynamically react to cursor hover (magnetic repulsion) and click events (shockwaves).
- **Parallax Navigation:** The 3D camera tracks scroll position to create deep, immersive parallax.
- **Theme Engine:** Fully supports Light and Dark mode, seamlessly transitioning the 3D environment's lighting.
- **Performance Optimized:** No heavy frameworks; built with pure HTML, CSS, JavaScript, and Three.js.

## Technologies Used
- HTML5 / CSS3
- Vanilla JavaScript
- Three.js (WebGL)

## Running Locally
To run this project locally, simply start a local web server in the root directory:
```bash
npx serve
```
Or using Python:
```bash
python -m http.server 8080
```
